# Triage Labels

Map each canonical triage role to the label used in this tracker.

| Canonical role    | Tracker label     | Meaning                                           |
| ----------------- | ----------------- | ------------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer must evaluate the issue                |
| `needs-info`      | `needs-info`      | Waiting for information from the reporter         |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an unattended agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation                     |
| `wontfix`         | `wontfix`         | Will not be implemented                           |

When a skill names a triage role, use its tracker label from this table.
To change the vocabulary, edit the Tracker label column.
